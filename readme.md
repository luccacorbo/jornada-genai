# Estudos em IA Generativa

Este repositório contém anotações de pesquisa guiada
sobre IA Generativa, LLMs e arquitetura moderna,
realizadas semanalmente (sextas-feiras).

O foco não é código, mas entendimento conceitual,
arquitetural e de trade-offs reais de mercado.

## Estrutura

- Uma entrega por sexta-feira
- Conteúdo em Markdown
- Baseado em perguntas-chave e reflexão pessoal
