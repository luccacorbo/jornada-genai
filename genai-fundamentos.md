# O que aprendi

## IA generativa x IA tradicional 

A IA generativa é uma "categoria" de inteligência artificial altamente treinada com bilhões de dados, projetada para criar novos conteúdos como textos, imagens, códigos, vídeos ou ate mesmo áudios a partir da captura de padrões. diferentemente de sistemas tradicionais que apenas classificam, recomendam ou tomam decisões baseadas em regras. 

IA tradicional costuma decidir 
IA generativa costuma explicar, criar ou interagir

IA Generativa não substitui IA tradicional.
Ela complementa, principalmente em tarefas onde linguagem, criatividade e flexibilidade são mais importantes que precisão absoluta.

## LLMs 

LLMs(large language models) é um tipo de IA treinado com grandes quantidades de dados de texto, esses dados podem incluir livros, artigos, código e outros formatos de texto.
São capazes de aprender padrões e relacionamentos no texto, o que os permite gerar textos com linguagem natural, traduzir idiomas, escrever diferentes tipos de conteúdos criativos e responder a perguntas de forma informativa.

## Desafios e limitações atuais 

- alucinações 
geração de informações falsas ou inventadas apresentadas com alto grau de confiança.

- consumo energético 
alto custo computacional e impacto ambiental do treinamento e operação. 

## Machine Learning

Na tradução direta - aprendizado de máquina é uma subarea da inteligencia artificial que permite que sistemas aprendam padrões a partir de dados, em vez de regras programadas manualmente. 

Dados + Respostas corretas → Modelo
Modelo + Novos dados → Resposta

Um modelo é uma máquina de reconhecer padrões

Tipos principais de Machine Learning

1 Aprendizado Supervisionado
Você fornece:
dados de entrada
a resposta correta

2️ Aprendizado Não Supervisionado
Você fornece:
apenas os dados
sem resposta correta

O modelo:
encontra padrões
agrupa dados parecidos


3️ Aprendizado por Reforço
O modelo:
toma ações
recebe recompensa ou punição
aprende por tentativa e erro

## Deep Learning

O deep learning na tradução livre "aprendizado profundo" é uma subcategoria do aprendizado de maquina, que, por sua vez é uma vertente da inteligência artificial. Ele é inspirado na estrutura e função do cérebro humano, especificamente em uma construção chamada redes neurais, estas redes possuem múltiplas camadas de neurônios artificiais, permitindo a elas processar dados de forma hierárquica e complexa. 

Deep Learning é uma abordagem de Machine Learning que utiliza redes neurais profundas para aprender representações complexas diretamente dos dados. Basicamente toma decisões baseadas em analisar características cada vez mais aprofundadas.

Machine Learning ensina o modelo com dados.
Deep Learning automatiza a extração de características relevantes a partir dos dados, reduzindo a necessidade de engenharia manual de atributos.

                            Inteligência Artificial

                                └── Deep Learning
